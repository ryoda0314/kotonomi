# ことのみ — 紹介映像

アプリの映像。1920×1080・30fps・約92秒、字幕とナレーション（Gemini TTS）。Remotion 4 で作る（アプリとは別のプロジェクト）。
作り方は姉妹アプリの映像（ことのめ `../../hangul/promo`、ことのえだ `../../keigo/promo`）にそろえた：アプリの画面を描き直し、
その横に一文ずつ言葉を置く。

見る人：TOEIC・TOEFL を受ける、日本語を話す人。単語帳を目で追っても、なかなか覚えられない人（`../CONCEPT.md`）。はじめの
一コマから問いかける（単語帳の5語と「見れば、分かる。」）。見て分かる語も、思い出して打とうとすると指が迷う。それから、
その「思い出して打つ」がアプリのひと回りでどう続くかを見せる。冒頭で迷った colleague が、翌日に戻ってきて、今度はひとりで
打てるところまで。

| | 画面 | 映像の言葉 |
|---|---|---|
| 問い | 単語帳の5語（アプリの最初のひと回り：colleague・retire・proposal・postpone・recommend）。英語の列が左から消え、同僚 だけが残って思い出す欄へ | 見れば、分かる。／でも、思い出して打てますか？ |
| | colleague を思い出して打つ（TypeRecall の見え方を3倍に）：collegue（g から紫）→ ⌫ → colleage（e から紫）→ ⌫ → colleague。語が鳴る | 見て分かる語も、打とうとすると、指が迷う。／思い出して打つと、綴りが手に残る。 |
| 名前 | アイコン（枝が伸び、葉が開き、青い実と紫の実がなる）と ことのみ | TOEIC・TOEFL の英単語を、指で覚える。 |
| はじめに | TOEIC・基本・日本語配列（選んだまま）で はじめる | TOEIC か TOEFL か、どこから始めるか。／基本・標準・発展は、始める場所の目安。 |
| 出会う | postpone（4 / 5）。語が鳴り、見ながら打つ。次のキーと押す指（[o] 右の薬指）。n のところで m を押すと、入らずに紫（[m] ではなく [n]：右の人さし指）、n を待つ | 意味と音といっしょに、見ながら打つ。／次のキーと、押す指が光る。違うキーは入らずに、正しいキーを待つ。 |
| | 例文の中で：例文を打つ（postponed は色付き）、訳。打ち終えると例文が鳴り、Enter で次へ | 例文の中で、もう一度打つ。 |
| 思い出す | 〜を延期する から（2 / 6）。キーボードは光らない。例文で を押すと、語が空欄の例文と訳。postpone を打つ。思い出せた | 少しあとに、日本語から思い出す。／出てこないときは、例文を手がかりに。 |
| また出会う | このひと回りのおわりに：はじめての語5つ、また出てくる語 colleague（紫） | 思い出しにくかった語は、翌日、また出てくる。／罰ではなく、もう一度出会うだけ。 |
| | 翌日：前に出会った語が、また出てきています（紫の罫）。同僚 から colleague を、今度は外れずに | 翌日、迷った colleague が。／今度は、ひとりで思い出せた。 |
| | 間の図：出会った日 → 翌日 → 3日 → 7日 → 16日 …（声が「三日」「七日」「十六日」と言うところで伸びる） | 思い出せた語は、間をのばして、また。 |
| 打つ | 例文を打つ（proposal の例文）。はじめの T は右の小指で Shift（キーの字が大文字になる） | 語を覚えるうちに、指がキーの場所を覚える。／点数も、速さも、測らない。 |
| 終わり | 名前、タブ（覚える・打つ・自分） | 点数も速さも測りません。登録はいりません。記録は、この端末に残ります。 |

語・意味・品詞・例文・訳は、アプリの中身（`../src/content`）をそのまま読む。画面の言葉はアプリの文言（`../src/lib/i18n/ja.ts`）、
キーボードの並びと指は `../src/lib/keys.ts`、思い出すときの紫と外れの数え方は `../src/lib/typing.ts` をそのまま使う。
ひと回りは、はじめに を選んだまま（TOEIC・基本・新しい語5つ）の最初のひと回り。colleague は2回外れたので（1回までは指の
すべり）また出てくる語になり、翌日に戻る（`../src/lib/record.ts`：出会った語は翌日、それから思い出せたら 3日・7日・16日…）。

## 声

- ナレーション：台本は `voice/lines.json`（画面の字幕とは別の、耳で聞く文。TOEIC・TOEFL は仮名で）。Gemini TTS
  （`gemini-3.1-flash-tts-preview`、声 Kore）を Vertex AI で。鍵は ことのは と同じサービスアカウント
  （`GOOGLE_SERVICE_ACCOUNT_KEY`・`GOOGLE_CLOUD_PROJECT`・`GOOGLE_CLOUD_LOCATION`、`../../english/.env.local`）。鍵はこの
  リポジトリに置かない。
- `--check` で書き起こして台本と並べた。「思い出せた語は」は「思い出せたことは」と聞こえたので「単語」に、「思い出しにくかった
  （単）語は」は二度とも崩れたので「迷った単語は」に言い替えた（台本の note）。いまの20本は、書き起こしが台本と一致する。
- 英語：アプリは端末の英語の声で言う（前もって作った声はない）。映像では、語と例文（E01〜E03）を Gemini TTS の別の声
  （Iapetus）で作り、ナレーションと聞き分けられるようにした。英語の行は、書き起こしが台本と一致するまで作り直す（三本とも
  一回目で一致）。ナレーションは英語の上に重ねない。
- 映像の時は、声の長さから決まる（`src/voice.json`。`src/timeline.ts` は声が言い終わってから次へ）。V10 の中の「三日」
  「七日」「十六日」の時は、クリップの無音から測って timeline.ts に書いた（V10 を作り直したら測り直す）。声のあいだは音楽が
  下がる（`src/Promo.tsx` の DUCKING）。声を作り直したら `music` も走らせ直す。
- 耳で聞いての確かめ（声の感じ・速さ・英語の発音の自然さ・音量のつり合い）は、機械ではできない。

## 作り方

```bash
cd promo
npm install
npm run assets     # 字（Google Fonts の倉庫から取り、映像の元とアプリの文言・語に出てくる字だけに切る。Python の fontTools）
npm run voice -- --env ../../english/.env.local   # ナレーションと英語（まだ無いものだけ。--force・--only V01・--check・--durations）
npm run music      # 音楽と小さな音（Python と numpy。映像の区切りに合わせて作る）
npm run studio     # 見ながら直す
npm run render     # out/kotonomi-promo.mp4
npm run stills -- 300 1240     # 1コマずつ out/stills に
```

- 画面はアプリの CSS と文言から描き直している（`src/ui.tsx`、`src/scenes/`）。パソコンで打つアプリなので、パソコンの幅で描く
  （720px から：タブは左の列、ページは 720px、キーボードはまるごと 15 キー幅の日本語配列）。アプリの見た目や言葉を変えたら、
  ここも変える。
- いつ何が起きるかは `src/timeline.ts`。打つ長さは打ち方（`src/anim.ts` の keys：一打ちごとに少し揺れる）から決まる。時を
  変えたら `music` を走らせ直す（音楽の最後の和音が終わりのカードに落ちる）。
- アイコンは `../design/make-icons.py` と同じ絵を SVG で描き直したもの（`src/fruit.tsx`）。名前の場面では枝が伸び、葉が開き、
  実がなる。アイコンの絵を替えたら、ここも替える。
- 字はアプリと同じ（IBM Plex Sans JP・IBM Plex Mono・しっぽり明朝）。言葉を変えたら `assets` を走らせ直す。
- 音楽と小さな音（打ったキー・入らなかったキー・押したところ・実がなる・思い出せた）は `scripts/music.py` が作る（姉妹の映像と
  同じ作り方）。だれかの曲は使っていない。
- 色は `remotion.config.ts` で bt709・yuv420p（姉妹と同じ。JPEG のコマのままだと薄い灰色が白く飛ぶ）。
- アプリの tsconfig と eslint からは外してある（`promo` は別のプロジェクト）。
- 見せる中身は `../CONCEPT.md` のとおり：点数・速さ・正答率・連続記録は出さない。
